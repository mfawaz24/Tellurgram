# Tellurgram

An unofficial Telegram client for Android, forked from [Mercurygram](https://github.com/jralo7/Mercurygram).

Tellurgram keeps all of Mercurygram's privacy and security improvements and adds its own:

- Enforced HTTPS
- Improved defaults for a better experience out of the box
